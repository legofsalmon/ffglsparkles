## Downloads

| File | For |
| --- | --- |
| `sparkles-*-macos.pkg` | **macOS: start here.** Double-click and follow the prompts. Installs for Arena, Avenue or both. |
| `sparkles-*-macos-universal.zip` | macOS, if you would rather copy the bundle by hand. Read `INSTALL.txt` inside: there is a Terminal step. |
| `sparkles-*-windows-x64.zip` | Windows. Copy `Sparkles.dll` into `Documents\Resolume Arena\Extra Effects`. |

Quit Resolume before installing; it only scans for plugins at launch. Sparkles
then appears in the **Sources** tab with the generators.

The parameters and presets are described in the
[README](https://github.com/legofsalmon/ffglsparkles#parameters).
